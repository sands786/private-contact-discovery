// Arcium
MXE Confidential Compute
Arcium's Multi-Party Execution environment runs PSI across distributed nodes. No single node has access to complete data. Results post back to Solana via a verified CPI callback from the Arcium MXE verifier PDA.
arcium-sdkMXE protocolVerifier CPI
// Cryptography
SHA-256 + Session Blinding
Contacts are hashed with a per-user random salt, then blinded with a per-session job ID before PSI — preventing rainbow table and cross-session correlation attacks. A Merkle root stores the commitment on-chain for integrity verification.
SHA-256Merkle rootSession blinding
// Solana
Anchor Program + Session PDAs
A full Anchor program manages session PDAs, identity registration, and handles MXE verifier CPI callbacks posting the intersection result. Session accounts are closeable to reclaim rent. All events are emitted for off-chain indexing.
